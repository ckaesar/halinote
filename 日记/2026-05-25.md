**正向代理**、**反向代理**、**网关**的区别：
1. **正向代理服务器**位于客户端旁边。您的笔记本电脑发送请求后，代理服务器会将请求转发出去，目标服务器永远不会看到您的真实 IP 地址。企业网络利用这种技术来执行策略、屏蔽网站和缓存流量。
2. **反向代理服务器**位于服务器旁边。客户端并不知道服务器后面有多少台机器。反向代理决定由哪台机器处理请求，终止 TLS 连接，并确保后端服务器与公共互联网隔离。NGINX 和 HAProxy 是常用的反向代理服务器，通常还会搭配前端的负载均衡器。
3. **API 网关**是一种反向代理，它的功能远不止路由流量。它还能处理身份验证、速率限制、API 密钥、版本控制和请求整形。如果没有 API 网关，每个微服务都必须自行实现验证、限流逻辑和请求日志记录。
**总结**：正向代理代表客户端，反向代理代表服务器，而 API 网关则是在十个服务需要一致地应用相同的身份验证和速率限制规则时添加的。

CLAUDE CODE如何防止长时间会话脱离上下文：
1. 预算削减：限制单个工具的输出结果。过大的输出结果将替换为内容参考。
2. 剪枝：剪掉最早的历史记录片段并发出边界标记。
3. 微压缩：按tool_use_id修剪工具轮次，以便提示缓存保持有效。
4. 上下文压缩：对整个历史记录的阅读时间进行预测。
5. 自动压缩：最后的手段。调用模型生成先前回合的完整摘要。
