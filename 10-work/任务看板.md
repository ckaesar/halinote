# 任务看板

> [!tip] 快速添加
> 在任意笔记中执行命令 `Tasks: Create or edit task`，或直接输入 `- [ ] 任务描述`。
> 任务会自动出现在下方对应状态区；点击复选框可切换完成状态。

## 今日焦点

```tasks
not done
(due before tomorrow) OR (scheduled before tomorrow)
sort by due
sort by priority
```

## 待办

```tasks
status.type is TODO
sort by due
sort by priority
group by due
```

## 进行中

```tasks
status.type is IN_PROGRESS
sort by due
sort by priority
```

## 已完成（近 7 天）

```tasks
status.type is DONE
done after 7 days ago
sort by done reverse
```

## 已取消

```tasks
status.type is CANCELLED
sort by description
```

## 任务写法

- 基本：`- [ ] 任务描述`
- 截止日期：`📅 2026-11-25`
- 计划日期：`⏳ 2026-11-20`
- 优先级：`⏫` 最高、`🔼` 高、`🔽` 低
- 重复任务：`🔁 every week`
- 创建日期由插件自动添加：`➕ 2026-11-19`

## 参考信息

- 当前状态流：`Todo` → `In Progress` → `Done`；`Cancelled` 用于取消
